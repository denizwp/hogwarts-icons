# Hogwarts Icons

Icon catalog and CDN for Hogwarts Legacy multiplayer projects. Browse it at <https://cdn.tools.deniz.cyou>.

## Using an icon

Files are served as they sit in this repository:

```
https://cdn.tools.deniz.cyou/icons/items/tools/wy_key.webp
```
